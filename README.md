# VaqCorp

Website for [vaqcorp.com](https://vaqcorp.com): Rafael Vaquero's inventions and the initiatives VaqCorp supports.

- `index.html`: the whole site (Spanish/English toggle built in).
- `img/`: images used on the page.
- Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

Preview before the custom domain is set: https://redaah.github.io/vaqcorp/
